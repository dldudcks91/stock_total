## 0. 배경

ma_touch 룰은 "MA에서 ±1% 이내로 정확히 찍은 자리"만 잡음. 강한 추세 종목 (예: 한미반도체)의 자리에서:
- 가격이 MA 한참 위에 있어도 추세 안에 있는 자리
- 사용자 직관: "일봉 MA10·MA20 수렴 + 그 자리에서 강한 장대양봉"
- → 이건 ma_touch가 못 잡는 다른 종류의 자리

이 자리를 잡는 룰을 탐색.

## 1. 사용자 의도 — 한미반도체 케이스

### 1-1. 사용자가 진입하고 싶었던 자리

| 날짜 | close | 다음 며칠 |
|---|---:|---|
| 2025-12-26 | 132,600 | 12/30→1/2 폭등 (+13.42%) |
| 2026-01-27 | 174,800 | 1/30 폭등 (+5.55%) |
| 2026-02-23 | 204,000 | 2/26 폭등 (+28.44%) |

공통점:
- 일봉 MA10·MA20 매우 가까이 위치 (수렴)
- 가격도 MA들과 가까이 (추격 아닌 진짜 자리)
- 그 자리에서 며칠 안에 강한 장대양봉 발생

### 1-2. 기존 ma_touch 가 못 잡는 이유

ma_touch 의 임계 = `0.2 × 일봉 range_7` ≈ close 의 1% 절대거리. 한미반도체 같이 강한 추세 종목에서 가격은 MA 위 5~30% 위치 → 1% 임계로는 절대 안 잡힘.

## 2. 룰 진화

### 2-1. 1차 안: gap_pct (%) 임계

```
조건 B: |MA10 - MA20| / MA20 ≤ 2%
```

문제: **gap_pct가 slope에 비례해서 자연 확장됨**.
- 가격이 봉당 r%씩 상승하면 gap_pct ≈ 5 × r%
- 추세 강한 종목은 gap_pct 자체가 크게 형성됨 → 강한 추세 종목 미달
- 한미반도체 1/27: gap_pct 2.99% — 임계 2% 초과로 컷

### 2-2. 2차 안: ATR20 정규화

```
gap_in_atr = (MA10 - MA20) / ATR20
조건 B: gap_in_atr ≤ 0.5
```

ATR20 = 14봉 평균 True Range 와 같은 변동성 지표. ATR로 정규화하면 가격 수준·변동성 무관 비교 가능.

- 한미반도체 1/27: gap_in_atr 0.47 → 통과 ✓
- 한미반도체 12/26: 0.11 → 통과 ✓
- 한미반도체 2/23: 0.46 → 통과 ✓

### 2-3. 3차 안: 주봉 정배열 필터 (큰 흐름 정합)

펌프 종목 (예: 티웨이홀딩스 5/21) 이 ATR 폭증으로 gap_in_atr 작아 보이는 문제 발견.

```
조건 E (추가): 진입일 주봉 MA10 > MA20
```

→ 티웨이홀딩스 5/21 (주봉 역배열) 컷.

### 2-4. 4차 안: close 위치 검사 (가격도 MA에서 가까이)

여전히 두산 6/1 같은 대형주 펌프 정점이 통과 — MA10·MA20는 수렴(0.017 ATR)이지만 close는 MA20보다 +29% 위.

```
조건 D (추가): (close - MA20) / ATR20 ≤ 2.5
```

또는 동등:
```
max(close, MA10, MA20) - min(close, MA10, MA20) ≤ 2.5 × ATR20
```

→ "세 점 모두 ATR20 의 2.5배 안에 좁은 띠로 모여 있을 것".

| 케이스 | 세점차/ATR20 | 평가 | 임계 2.5 |
|---|---:|---|:-:|
| 한미 12/26 | 2.17 | 사용자 OK | ✓ |
| 한미 1/27 | 0.51 | 사용자 OK | ✓ |
| 한미 2/23 | 0.84 | 사용자 OK | ✓ |
| 한미 4/17 | 0.56 | 정상 | ✓ |
| 두산 6/1 | 2.92 | 펌프 | ✗ |
| 티웨이 5/21 | 6.15 | 펌프 | ✗ |
| 현대모비스 2/26 | 4.30 | 손실 | ✗ |
| 고려아연 10/14 | 6.16 | 손실 | ✗ |

→ **임계 2.5 ATR이 깔끔한 분리선**.

## 3. 룰 (최종 후보)

```
ATR_WIN = 20
GAP_IN_ATR_MAX = 0.5
CLOSE_MA_ATR_MAX = 2.5
INTRA_MIN = 0.05
MAX_HOLD_BARS = 10

Z (수렴자리) = 
    MA10 > MA20
    AND close > MA20
    AND |MA10 - MA20| / ATR20 ≤ 0.5
    AND (close - MA20) / ATR20 ≤ 2.5       # 가격도 MA 가까이
    AND 주봉 MA10 > MA20                    # 큰 흐름 정배열

fresh_Z = 오늘 Z AND 어제 Z 아님              # 진입 시그널

★T = Z AND intraday_ret ≥ 5% AND close > open  # 장대양봉 익절

[엔진]
진입 = fresh_Z 발생일 종가
보유 = Z 유지 중
출구 (우선순위):
    A. STOP   = MA10 ≤ MA20 또는 close ≤ MA20 (정배열 깨짐) → 즉시 종가
    B. ★T     = Z 유지 중 장대양봉 → 그날 종가 (익절)
    C. TIMEOUT = 10봉 안 ★T 없으면 그날 종가
```

| Q0 (좁음/재수렴 0~0.16) | **+5.82%** | 51.4% |
| Q4 (펼침/파라볼릭 0.86~2.12) | −0.02% | 55.6% |

→ fan≤0.5 시 평균 +3.87%. **"주봉 부채꼴 과열은 거른다"는 직관 입증.**

한미 주봉 신호 (차트 판독과 일치):
- 4/12 (=4/17, **fan 0.36 좁음**) → +36% (일봉선 애매했으나 주봉 정석 눌림)
- 3/22 (=3/24, **fan 1.12 펼침**) → −16% (주봉 파라볼릭 = 실패 설명됨)

비교: **주봉 = 신호(어디서 사나) 강함(평균↑·큰 자리 선별)**, **일봉 룰 D = 관리(어떻게 손절하나) 강함(승률 48%·STOP 43%)**.
