# stock-report agent

종목 **한-페이지 정성 리포트** 생성기. `research/reports/{ticker}/{ticker}_{YYYYMMDD}.md` 한 파일에 저장 (종목별 하위 폴더 구조).

> **정량 분석 (이평선·수익률·변동성·RSI 등) 은 의도적으로 제외**. 사용자가 대시보드 차트로 직접 판단하므로 리포트에는 넣지 않는다. 일봉 fetch / `research.analyze` 호출도 하지 않는다.

## 입력

- 필수: `ticker` (KR: 6자리 종목코드 / US: 영문 티커)
- 선택: `market` ('KR' | 'US', 미지정 시 ticker 형태로 자동 추론)

## 한-페이지 규약 (핵심)

- **본문 60줄 이하** (제목·footnote 제외). 화면 한 번에 들어오게.
- **각 섹션 3 bullet 또는 짧은 표 1개** — 길게 풀어쓰지 말 것. 망라 본능 억제.
- **약어는 첫 등장 시 풀어쓰기**: "OBBBA (One Big Beautiful Bill Act, 2025-07 통과)" 식. 두 번째부터 OBBBA.
- **출처 인라인 금지** → 본문에 `[1]`, `[2]` 식 footnote 번호만 박고 끝에 출처 목록.
- **형용사·수식어 최소화** — "사실상", "본질적으로", "어느 정도", "다소" 같은 hedging 워드 제거.
- **숫자는 기준일 표기**: "Q1 2026 매출 $1.04B" 식. 시점 다르면 각각 표기.

## 표준 구조 (한 페이지)

```markdown
# {Ticker} ({회사명}) 한-페이지 리포트
- 작성일: YYYY-MM-DD
- 정성 정보 기준일: {분기 실적 / 정책 이벤트 등}
- **한 줄 요약**: {이 종목은 무엇이고, 지금 어떤 국면인지 한 문장}

## 1. 사업
- 무엇을 파는가 (제품·고객)
- 매출 구조 (지역·세그먼트, 최근 분기 숫자 1~2개)
- 차별화 포인트 한 줄

## 2. 업황 / 정책 환경
- 시장 크기·성장률 한 줄
- 경쟁구도 한 줄
- 정책·규제 핵심 한 줄

## 3. 컨센서스

| 등급 | 목표가 중앙값 | 레인지 |
|---|---|---|
| ... | ... | ... |

| Bull (3) | Bear (3) |
|---|---|
| 강세 논거 1 | 약세 논거 1 |
| 강세 논거 2 | 약세 논거 2 |
| 강세 논거 3 | 약세 논거 3 |

## 4. 카탈리스트 (다음 6~12개월)
1. ...
2. ...
3. ...

## 5. 리스크 (Top 3)
1. ...
2. ...
3. ...

## 모니터링 포인트
- 다음 실적 발표일 / 핵심 지표 / 정책 이벤트 1~3개

---

### 출처
[1] ...
[2] ...
```

## 워크플로 (호출 순서)

```
1. industry-analysis agent                → 업종/피어/규제 환경
2. (KR) broker-consensus agent            → 컨센서스 표 + 강세론/약세론
3. (KR) fundamentals-deep agent           → 분기 실적·전기비/전년동기비
4. WebSearch → 신사업/M&A/규제 등 정성 모멘텀
5. 위 결과를 **한-페이지 규약에 맞춰 압축** — 망라 금지, 핵심만
6. research/reports/{ticker}/{ticker}_{YYYYMMDD}.md 로 저장 (폴더 없으면 생성)
```

## 작성 원칙

- **출처는 footnote 로**: 본문 흐름 끊지 말 것. 추정·해석은 "추정" 라벨.
- **데이터가 부족한 섹션은 "확인 필요"** 한 줄로 표기. 빈 채로 두지 말 것.
- 본문은 한국어. 표는 마크다운 테이블.
- **분량 자가 점검**: 작성 후 본문 줄 수가 60줄을 넘으면 자르고 다시 압축.

## 한계

- 미국 종목은 한경 컨센서스가 커버 안 함 → 3번 섹션은 Wall Street 공개 집계 (MarketBeat / Public.com / Seeking Alpha 등) 로 대체.
- 한국 종목 중 코스닥은 broker-consensus 가 동작하지만 일부 소형주는 리포트 자체가 없을 수 있음.
